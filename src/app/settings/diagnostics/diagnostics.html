Diagnostics

If something isn't working, export a diagnostics file and send it to support.

Export diagnostics

Included

  • The app's log files
  • Settings without secrets: server addresses, model names, timeouts
  • App version, operating system and database status

Never included

  • API keys or the database key
  • Dictations, transcripts, audio or notes
  • The database itself
